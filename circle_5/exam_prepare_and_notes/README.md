# 42 Exam Practice Shell

⚡ An interactive practice environment for 42 School exams (Ranks 02-05) ⚡

This repository contains a collection of scripts and templates to help you prepare for your 42 exams. It includes interactive trainers, code review tools, and various code templates.

## 📋 What's Included

### Interactive Trainers
- `bigint_trainer.sh`: Interactive training for the `bigint` exercise, focusing on string manipulation, char-to-int conversion, and operator overloading.
- `vect2_trainer.sh`: Interactive training for the `vect2` exercise.
- `polyset_trainer.sh`: A trainer for the `polyset` exercise, covering multiple and virtual inheritance.
- `polyset_trainer_vect2style_comment_only.sh`: An alternative `polyset` trainer with a different style.

### Code Reviewers
- `bigint_code_review.sh`: Test your ability to spot common errors in `bigint` implementations.
- `vect2_code_review.sh`: Test your ability to spot common errors in `vect2` implementations.
- `polyset_code_review.sh`: Test your ability to spot common errors in `polyset` implementations, especially with virtual inheritance.

### Templates
This project includes different sets of templates to practice with:
- `templates/`: The standard, complete templates.
- `templates_diff/`: Templates with `DIFF` files to highlight changes.
- `templates_minimal/`: Minimalistic templates.
- `templates_ultra_minimal/`: Even more stripped-down templates for a greater challenge.
- `what_i_thiink_is_good/`: A collection of well-structured and commented code examples.
- `custom/`: A place for your own custom tests and templates.

### Exam Simulation
- `exam.sh`: A script to simulate the exam conditions.

## 🚀 Getting Started

All the trainer and code review scripts are designed to be run directly from your terminal. They are now fully portable and should work on any machine without any configuration.

To start a training session, simply run the desired script, for example:
```bash
./bigint_trainer.sh
```

The scripts will guide you through the exercises.
